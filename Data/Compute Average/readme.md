# 📊 Compute Average from File (Code in Place)

> *A Python file-handling assignment from Stanford University's **Code in Place** course focused on reading external data, working with lists, and performing basic arithmetic.*

---

## 📜 About the Assignment

Instead of hardcoding large amounts of data directly into our code, real-world programs frequently read data from external files. This allows the exact same code to operate dynamically on different files with identical structures!

### 🎯 Objective

* The starter code handles loading a list of numbers from an external file (`numbers.txt`) into a list called `number_list`.
* Your task is to **compute the average** of the values in `number_list` and **print out the result**.

---

## 💻 Example Run

If the file `numbers.txt` contains four numbers:

```text
1
5
7
9

```

Running your program should produce the following console output:

```text
Average: 5.5

```

---

## 🛠️ Implementation Details

* **File Handling:** The starter code reads the data line-by-line or parses the text file into a usable list format.
* **List Processing:** Iterate through the numbers or use built-in functions (like summing the elements and dividing by the total count) to find the average.
* **Flexibility:** The solution will adapt to any file structured in the same way, demonstrating the power of data abstraction.

---

## 🚀 Getting Started

1. Check the file icon in your workspace to view the contents of `numbers.txt`.
2. Write the logic to calculate the average of `number_list`.
3. Print the final average matching the expected format.
4. Click **"Check Correct"** to test your solution against the autograder!
