# 🤖 Karel – Piles Assignment

A Stanford Karel exercise where Karel picks up all the beepers from three piles in the first row of the world.

## 📋 Assignment Description

Karel starts at the left side of a grid world. The goal is to write a program that makes Karel **pick up all the beepers** from the first row, leaving the world completely empty.

The world contains **3 piles**, each with **10 beepers**, spaced 2 steps apart.

## 🗺️ World Layout

```
[ Karel ] [ ] [Pile 1] [ ] [Pile 2] [ ] [Pile 3]
  col 1   col2  col 3  col4  col 5  col6  col 7
```

## 🧠 Key Concepts

- **`for` loops** – repeat an action a fixed number of times
- **`pick_beeper()`** – picks up one beeper from Karel's current position
- **`move()`** – moves Karel one step forward
- **Indentation** – Python uses indentation to define what's inside a loop

## 🚀 How to Run

```bash
python main.py
```
