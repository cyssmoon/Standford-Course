# Karel Beeper Picker 🤖

A simple Karel the Robot program that moves, picks up a beeper, and moves again. This is an introductory assignment from Stanford's [Code in Place](https://codeinplace.stanford.edu) course.

## Description

Karel starts facing east in a grid world. There is a beeper placed one step ahead of Karel's starting position. The program instructs Karel to:

1. Move one step forward
2. Pick up the beeper
3. Move one more step forward

## How to Run

1. Open the Karel editor (the `main.py` tab)
2. Paste the code below
3. Click the **Run** button

## Expected Result

After running the program, Karel will have moved two positions to the right and the beeper will be gone from the grid (Karel picked it up).

```
+    +    +    +

+    +   🤖   +
```

## Concepts Used

- `move()` — moves Karel one step forward in the direction it is facing
- `pick_beeper()` — picks up a beeper from the current tile
